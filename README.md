# 🏨 Hospitality Reservation System - EDA Project

This project is an Exploratory Data Analysis (EDA) of a Hospitality Reservation System. It includes data extraction using SQL, data processing with Pandas, visualizations, and a summary presentation. The goal is to understand booking patterns, customer behavior, and cancellation trends.

## 📁 Included Files

-  – Raw dataset
- – Jupyter Notebook with analysis
- Project summary and insights ppt

## 🎯 Objective

To analyze hotel reservation data using SQL and Python to gain meaningful insights that can support business decisions in the hospitality industry.

## 🛠️ Tools & Technologies Used

- **SQL** – Data extraction
- **Python** – Data processing
- **Pandas** – Data manipulation
- **SQLAlchemy** – SQL to Python connectivity
- **Matplotlib / Seaborn** – Visualization
- **Jupyter Notebook** – Interactive analysis
- **PowerPoint** – Final project presentation

## 🧠 Key Steps in Project

1. Connected SQL database to Python using SQLAlchemy
2. Fetched reservation data into Pandas DataFrame
3. Cleaned and preprocessed the dataset
4. Performed data exploration and analysis
5. Created visualizations for key insights
6. Summarized findings in a presentation

## 💡 Key Insights

- Peak booking months and customer trends
- Cancellation rates across different segments
- Lead time impact on cancellations
- Revenue patterns and average daily rates
- Country-wise guest distribution

## 📈 Sample Visualizations

- Line charts: Bookings by month
- Bar plots: Cancellations by deposit type
- Heatmaps: Feature correlations
- Pie charts: Market segment shares

## 📌 How to Run

1. Clone the repository
2. Open the `.ipynb` file in Jupyter Notebook
3. Install required packages
4. Run all cells to view the analysis and visualizations
